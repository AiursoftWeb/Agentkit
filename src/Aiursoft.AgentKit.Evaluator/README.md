# Aiursoft.AgentKit.Evaluator

A deterministic, domain-neutral evaluation engine for observed agent behavior.

It evaluates assertions against tool traces, JSON state, text responses, and iteration counts. It does not seed applications, provide a model transport, define a scenario fixture schema, or know about boards, cards, users, authorization, web hosting, or reports containing credentials.

Consumers define their own case fixtures, evidence capture, dimensions, weights, and reporting policy.
